High-signal notes for agents working in this repo. `CLAUDE.md` is stale

## Commands

```bash
npm run dev        # Vite dev server on :8000 (open:false)
npm run build      # Runs "icons" then "vite build" -> dist/
npm run preview    # Preview the production build
npm run icons      # Regenerate PWA icons from public/icon.svg (uses sharp)
npx prettier --write .   # Format. No lint, no typecheck, no tests exist.
```

There is no test suite, linter, or typecheck. Prettier (`.prettierrc`: single
quotes, trailingComma es5, htmlWhitespaceSensitivity ignore, proseWrap always)
is the only quality gate.

Both `bun.lock` and `package-lock.json` are committed. CI uses Bun; local dev
can use either. Install with `npm install` or `bun install`.

## Build quirks

- `npm run build` regenerates icons **before** building:
  `scripts/generate-icons.mjs` reads `public/icon.svg` and overwrites
  `public/images/favicon-{32,128,192,512}.png`, `public/favicon.ico`, and the
  root `favicon.ico`. Never hand-edit those — edit `public/icon.svg` and re-run
  `npm run icons`.
- No `service-worker.js` file exists in the repo. The PWA service worker is
  generated at build time by `vite-plugin-pwa` (Workbox) from `pwa.config.js`,
  which imports tokens from `src/pwa-tokens.js`.
- `manifest.json` at the repo root is legacy/unused — the real web manifest is
  generated by `vite-plugin-pwa` from `pwa.config.js`.
- `pwa.config.js` runtime-caches `**/*.{js,css,html,ico,png,svg,woff2}` with
  navigateFallback `/offline.html` (in `public/`). DuckDuckGo autocomplete
  requests are `NetworkOnly`.
- Colors in `src/pwa-tokens.js` must stay in sync with
  `src/styles/variables.css` (see comment at top of `pwa-tokens.js`).

## Architecture

Entry: `index.html` loads `/src/main.js`, which imports the three stylesheets
(`src/styles/{fonts,variables,layout}.css`) and, on `DOMContentLoaded`,
dynamically imports five Web Components: `Clock`, `Tabs`, `Commands`, `Search`,
`NewsFeed`. All components use Shadow DOM + `<template>` tags and are
registered as custom elements (`<clock-component>`, `<tabs-component>`,
`<commands-component>`, `<search-component>`, `<newsfeed-component>`).

- `src/components/NewsFeed.js` — Hacker News front-page list below the command
  grid. Fetches the Algolia HN API (`hn.algolia.com/api/v1`, NetworkOnly in the
  service worker), refreshes every 10 min, fails silently. Workspace-agnostic.

- `src/config.js` — `CONFIG` (delimiters, default search = Brave,
  suggestionLimit, workspace storage key) and `COMMANDS` Map. **Add/edit
  shortcuts here.** Each entry:
  `{ name, url, searchTemplate?, workspace, suggestions? }`.
- `src/lib/WorkspaceManager.js` — singleton. Groups `COMMANDS` by `workspace`
  field (currently `personal`, `dev`), persists active workspace to
  `localStorage` key `m1n-active-workspace`, and dispatches a `workspacechange`
  `CustomEvent` on `window` when switched. Components subscribe to this event.
- `src/lib/UsageTracker.js` — persists per-command `{count, lastUsed}` to
  `localStorage` key `m1n-command-usage`. Powers the "wide" command tiles in
  `Commands.js` (recent-then-frequent, top 2).
- `src/components/Search.js` — the command parser. Three input modes: bare key
  (navigate), `key<space>query` (uses `searchTemplate`), `key/path` (origin +
  path). Falls back to `CONFIG.defaultSearchTemplate` (Brave). DuckDuckGo `/ac/`
  endpoint supplies autocomplete suggestions. Commands are case-insensitive
  unless `CONFIG.commandCaseSensitive` is true.

Keyboard shortcuts (for context when editing `src/main.js` or `Search.js`): `/`
opens search empty; any printable key opens search seeded with that key;
`Alt`/`Meta`+`1-9` switches workspace; `Ctrl+Shift+R` posts `UPDATE_CACHE` to
the service worker.

## Deploy

Automated via SourceHut builds
(`.`build.yml`), **not** Vercel. On push: install Bun → `bun install`→`bun run
build`→`rsync --delete -rv ./dist/
pgs.sh:/start-m1n-land`. Requires the `SSH_DEPLOY_KEY`secret. Failure emails`~m1n/git.sr.ht`.

`docker-compose.yml` is stale: it only mounts `index.html` into nginx on :8181,
which won't resolve `/src/main.js` or the Vite bundle. Don't use it to serve the
current app; use `npm run dev` or `npm run preview`.

## Style conventions

- Vanilla JS ES6+ with classes, private fields (`#field`), async/await. No
  framework, no TypeScript, no transpiler beyond Vite.
- Fonts are bundled via `@fontsource` (Outfit + IBM Plex Mono) — no Google Fonts
  requests.
- Theming via CSS custom properties in `src/styles/variables.css`; auto
  dark/light through `@media (prefers-color-scheme: light)`.
- Comments are sparse by convention; match the surrounding code.
